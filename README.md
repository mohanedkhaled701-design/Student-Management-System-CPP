# Student Management System in C++

## Project Description
A simple console-based application developed using C++ to manage student records.

## Features
- Add a new student
- Display all students
- Search for a student by ID
- Delete a student by ID
- Save student records in a text file

## Student Information
Each student record contains:
- ID
- Name
- Department
- GPA

## Technologies Used
- C++
- Struct
- Vector
- File Handling

## How to Run
1. Open the source code in Visual Studio 2022.
2. Build the project.
3. Run the application.
4. Choose an operation from the menu.

## Data Storage
Student records are stored in a file named students.txt.
